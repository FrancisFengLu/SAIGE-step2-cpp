SKAT-O Algorithm — Complete Pipeline Reference

This document provides a comprehensive, mathematically precise reference for the SKAT-O (Sequence Kernel Association Test — Optimal) algorithm as implemented in skat.cpp. Every formula, variable name, and step corresponds directly to the C++ implementation, which is itself a faithful port of the R SKAT package (SKAT:::Met_SKAT_Get_Pvalue with method="optimal.adj").

Vectors [m×1] Matrices [m×m] Scalars Test Statistics / P-values

1. Overview: What is SKAT-O?

SKAT-O (Lee et al., 2012) is the optimal unified test that combines two complementary gene-level tests:

SKAT (Variance-Component Test, ρ = 0)

Tests whether any individual variant in the region has an effect. Powerful when effects are sparse or in opposite directions.

$$Q_{\text{SKAT}} = \mathbf{S}^\top \mathbf{W} \mathbf{S}$$

BURDEN (Collapsing Test, ρ = 1)

Tests whether variants collectively shift the trait. Powerful when most variants have effects in the same direction.

$$Q_{\text{Burden}} = \left(\sum_j w_j S_j\right)^2$$

SKAT-O interpolates between these two extremes via a mixing parameter $\rho \in [0, 1]$:

$$Q(\rho) = (1 - \rho)\, Q_{\text{SKAT}} + \rho\, Q_{\text{Burden}}$$

The key idea: rather than choosing one test a priori, SKAT-O searches over a grid of $\rho$ values and reports the minimum p-value, corrected for the search. The correction is done via numerical integration over the null distribution of the minimum p-value statistic $T_{\text{SKAT-O}} = \min_\rho\, p(\rho)$.

2. Input

The SKAT-O algorithm receives the following inputs from the region-testing pipeline (get_SKAT_pvalue(), line 1781 of skat.cpp):

3. Step 1 — Per-Rho Q Statistics

1

Compute Q(ρ) for each ρ in the grid

For each $\rho_k$ in the grid, the test statistic $Q(\rho_k)$ is a weighted combination of the SKAT and Burden statistics:

$$Q(\rho_k) = (1 - \rho_k)\, \underbrace{\mathbf{S}^\top \mathbf{S}}_{Q_{\text{SKAT}}} \;+\; \rho_k\, \underbrace{\left(\sum_j S_j\right)^2}_{Q_{\text{Burden}}}$$

This can be written compactly using the correlation matrix $\mathbf{R}_\rho = (1-\rho)\mathbf{I} + \rho\, \mathbf{1}\mathbf{1}^\top$:

$$Q(\rho) = \mathbf{S}^\top \mathbf{R}_\rho\, \mathbf{S}$$

C++ implementation (lines 1903–1908):

// Q(rho) = (1-rho) * Score'*Score + rho * (sum(Score))^2
double Q_rho = (1.0 - rho) * arma::dot(Score, Score)
             + rho * sum_score * sum_score;
Note: Internally, SKAT-O works with $Q/2$ and $\Phi/2$ (line 1356: arma::mat Phi_half = Phi * 0.5; line 1454: Q_all(k) = Q_rho / 2.0). Since p-values are scale-invariant, this halving does not affect the result. It matches the R SKAT package convention where SKAT_META_Optimal passes Phi/2 to SKAT_META_Optimal_Get_Pvalue.

4. Step 2 — Per-Rho Eigenvalues

2

Eigenvalues of the null distribution for Q(ρ)

Under the null hypothesis, $Q(\rho)$ follows a distribution of the form $\sum_j \lambda_j^{(\rho)}\, \chi^2_1$, where $\lambda_j^{(\rho)}$ are the eigenvalues of $\mathbf{R}_\rho^{1/2}\, \Phi\, \mathbf{R}_\rho^{1/2}$. Computing these eigenvalues is done via the Cholesky decomposition of $\mathbf{R}_\rho$.

Cholesky approach (lines 1462–1489)

For each $\rho_k$:

  1. Form $\mathbf{R}_\rho = (1-\rho)\mathbf{I} + \rho\, \mathbf{1}\mathbf{1}^\top$
  2. Compute the upper Cholesky factor: $\mathbf{R}_\rho = \mathbf{L}^\top \mathbf{L}$
  3. Form $\Phi_\rho = \mathbf{L} \cdot (\Phi/2) \cdot \mathbf{L}^\top$
  4. Eigendecompose: $\lambda^{(\rho)} = \text{eig\_sym}(\Phi_\rho)$
  5. Filter eigenvalues using R's Get_Lambda rule
// L = chol(R.M)  -- upper Cholesky
arma::mat R_M = (1.0 - rho) * arma::eye(p_m, p_m)
              + rho * arma::ones(p_m, p_m);
arma::mat L;
arma::chol(L, R_M);
arma::mat Phi_rho = L * Phi_half * L.t();

Eigenvalue filtering (lines 579–587)

The filter_eigenvalues_R() function matches R's Get_Lambda:

$$\text{threshold} = \frac{\text{mean}(\lambda_j \mid \lambda_j \geq 0)}{10^5}$$ $$\lambda_{\text{filtered}} = \{\lambda_j \mid \lambda_j > \text{threshold}\}$$
Special cases: ρ = 0 and ρ = 1

When ρ = 0 (pure SKAT), $\mathbf{R}_0 = \mathbf{I}$, so $\lambda^{(0)} = \text{eig}(\Phi)$. See compute_phi_rho_eigenvalues() line 590.

When ρ = 1 (pure Burden), $\mathbf{R}_1 = \mathbf{1}\mathbf{1}^\top$, which has rank 1 with eigenvalue $m$. Thus $Q(1) / \sum_{ij} \Phi_{ij} \sim \chi^2_1$. The function returns a single eigenvalue $= \text{accu}(\Phi)$ (line 599).

General case eigenstructure of R_ρ

The function compute_phi_rho_eigenvalues() (line 589) also implements a direct spectral approach for intermediate $\rho$. The eigenvalues of $\mathbf{R}_\rho$ are:

$$(1-\rho) \text{ with multiplicity } (m-1), \quad (1-\rho+m\rho) \text{ with multiplicity } 1$$

The square root is computed via the projection onto $\mathbf{1}$: $\sqrt{\mathbf{R}_\rho} = \sqrt{1-\rho}\,(\mathbf{I} - \mathbf{P}) + \sqrt{1-\rho+m\rho}\,\mathbf{P}$ where $\mathbf{P} = \mathbf{1}\mathbf{1}^\top / m$ (lines 614–617).

5. Step 3 — Per-Rho P-Values

3

P-value for Q(ρ) via Davies or Liu

For each $\rho_k$, compute $p_k = P(Q_{\text{null}} > Q(\rho_k))$ where $Q_{\text{null}} \sim \sum_j \lambda_j^{(\rho_k)} \chi^2_1$. The primary method is Davies; if it fails, Liu moment-matching is used as fallback.

5a. Davies Method (Algorithm AS 155)

Davies (1980) computes the tail probability of a linear combination of chi-squared(1) variables by numerically inverting the characteristic function. The implementation in skat.cpp (lines 59–384, namespace qfc_impl) is a direct port of the qfc algorithm from the CompQuadForm R package bundled in SKAT.

$$P\left(\sum_{j=1}^{r} \lambda_j \chi^2_1 > q\right) = \frac{1}{2} - \frac{1}{\pi} \int_0^\infty \frac{\sin\!\left[\sum_j n_j \arctan(\lambda_j u) - q u\right]} {u \prod_j (1 + \lambda_j^2 u^2)^{n_j/4}}\, du$$

The algorithm (entry point: line 263, qfc()) works as follows:

  1. Find the truncation point utx such that the tail of the integral is negligible (findu(), line 184)
  2. Find the integration interval from the range of the distribution (ctff(), line 129)
  3. Optionally add a convergence factor $\tau^2$ if the integrand oscillates (cfe(), line 232)
  4. Numerically integrate via trapezoidal rule (do_integrate(), line 208)
  5. Result: $P(Q < q) = 0.5 - \text{integral}$ (line 361)
// Call: qfc returns P(Q < q) in res
qfc_impl::qfc(lb.data(), nc.data(), df.data(), n,
               sigma, q, lim, acc, trace, &ifault, &res);
double pval = 1.0 - res;  // We need P(Q > q)

The wrapper davies_pvalue() (line 387) filters near-zero eigenvalues, handles the single-eigenvalue special case, and falls back to Liu if the qfc algorithm reports failure (ifault != 0) or returns a p-value outside $(0, 1]$.

Accuracy: Davies uses acc = 1e-6 and lim = 10000 iterations (line 418–419), matching the R defaults.

5b. Liu Moment-Matching Method (Fallback)

When Davies fails, liu_pvalue() (line 456) approximates the distribution of $Q = \sum_j \lambda_j \chi^2_1$ by a scaled (non-central) chi-squared distribution matching the first 4 cumulants. This is from SKAT:::SKAT_liu.MOD.Lambda.

Cumulant computation

$$c_k = \sum_{j} \lambda_j^k \quad \text{for } k = 1, 2, 3, 4$$ $$s_1 = \frac{c_3}{c_2^{3/2}}, \quad s_2 = \frac{c_4}{c_2^2}$$

Parameter fitting

$$\text{If } s_1^2 > s_2: \quad a = \frac{1}{s_1 - \sqrt{s_1^2 - s_2}}, \quad \delta = s_1 a^3 - a^2, \quad \ell = a^2 - 2\delta$$ $$\text{Else: } \quad \delta = 0, \quad \ell = 1/s_2$$

where $\ell$ is the degrees of freedom and $\delta$ is the noncentrality parameter. The mean and sigma are:

$$\mu_Q = c_1, \quad \sigma_Q = \sqrt{2\, c_2}$$

Normalization and p-value

$$Q_{\text{norm}} = \frac{Q - \mu_Q}{\sigma_Q} \cdot \sqrt{2\ell + 4\delta} + \ell + \delta$$ $$p = P\!\left(\chi^2(\ell, \delta) > Q_{\text{norm}}\right)$$ 
// Normalize Q to the chi-squared scale (line 496)
double Qnorm = (q - muQ) / sigmaQ * std::sqrt(2.0 * l + 4.0 * delta) + l + delta;

// Compute p-value (line 502-508)
if (delta > 1e-6) {
    boost::math::non_central_chi_squared ncchi2(l, delta);
    return boost::math::cdf(boost::math::complement(ncchi2, Qnorm));
} else {
    boost::math::chi_squared chi2(l);
    return boost::math::cdf(boost::math::complement(chi2, Qnorm));
}

6. Step 4 — Shared Parameters (SKAT_META_Optimal_Param)

4

Shared decomposition for the integrand

Before the integration step, SKAT-O decomposes $\Phi/2$ into orthogonal components that are shared across all $\rho$ values. This is done in SKAT_META_Optimal_Param (ported at lines 1362–1429).

6a. The Z Decomposition

The key idea is to separate $\Phi/2$ into a component aligned with $\mathbf{1}$ (the Burden direction) and an orthogonal component (the SKAT-specific variance):

$$\mathbf{Z}_{\text{item1}} = (\Phi/2) \cdot \mathbf{1} \quad \text{(column sums vector, [m \times 1])}$$ $$\mathbf{ZMZ} = \frac{\mathbf{Z}_{\text{item1}}\, \mathbf{Z}_{\text{item1}}^\top}{\text{accu}(\Phi/2)} \quad \text{(projection onto Burden, [m \times m])}$$ $$\mathbf{W}_{3.2} = \Phi/2 - \mathbf{ZMZ} \quad \text{(orthogonal complement)}$$ 
// Lines 1366-1380: Z decomposition
arma::vec Z_item1_1 = Phi_half * ones_m;       // column sums
double sum_Phi_half = arma::accu(Phi_half);
arma::mat ZMZ = (Z_item1_1 * Z_item1_1.t()) / sum_Phi_half;
arma::mat W3_2_t = Phi_half - ZMZ;

Shared eigenvalues $\lambda_{\text{shared}}$

These come from eigendecomposing the orthogonal component $\mathbf{W}_{3.2}$ with R's Get_Lambda filter (lines 1388–1397):

$$\lambda_{\text{shared}} = \text{filtered\_eig}(\mathbf{W}_{3.2})$$

Cross-term variance: W3.3.item

$$\text{W3.3.item} = 4 \cdot \text{accu}\!\left(\mathbf{ZMZ} \odot (\Phi/2 - \mathbf{ZMZ})\right)$$

This captures the covariance between the Burden direction and the SKAT-specific variance (line 1400: double W3_3_item = arma::accu(ZMZ % (Phi_half - ZMZ)) * 4.0).

Intuition: $\tau_k$ represents the expected contribution of the chi-squared(1) mixing variable to $Q(\rho_k)$ under the null. The integration in Step 7 conditions on this mixing variable, so $\tau_k$ scales the integrand's threshold.

7. Step 5 — Per-Rho Liu Parameters

5

Liu moment-matching parameters for each ρ

For each $\rho_k$, the per-rho eigenvalues $\lambda^{(\rho_k)}$ (computed in Step 2) are used to fit Liu moment-matching parameters. These are different from the shared parameters in Step 4, and are needed to map the minimum p-value back to the Q-scale in Step 6.

The function liu_params() (line 527) returns:

l_k From cumulant-matching (see Liu section) Degrees of freedom for chi-squared approx
delta_k From cumulant-matching Noncentrality (often 0) 
// Line 1500: Liu params from per-rho eigenvalues
liu_rho_vec[k] = liu_params(lambda_temp);
Critical distinction: The per-rho Liu parameters ($\mu_{Q,k}$, $\sigma_{Q,k}$, $\ell_k$) are computed from the per-rho eigenvalues $\lambda^{(\rho_k)}$. The shared parameters ($\text{MuQ}$, $\text{VarQ}$, $\lambda_{\text{shared}}$) are computed from $\mathbf{W}_{3.2}$'s eigenvalues. Mixing these up is a common source of implementation bugs.

8. Step 6 — Minimum P-Value and pmin_q Mapping

6

Map pmin back to Q-scale for each ρ

Find $p_{\min} = \min_k\, p_k$ across all $\rho$ values. Then, for each $\rho_k$, compute the Q threshold pmin_q[k] that corresponds to $p_{\min}$ in the null distribution at $\rho_k$. This is a three-step mapping:

  1. Inverse CDF (qchisq): Map $p_{\min}$ to the chi-squared scale using the per-rho Liu df $\ell_k$:
    $$q_{\text{org}} = F^{-1}_{\chi^2(\ell_k)}(1 - p_{\min})$$
  2. Unstandardize: Map from the chi-squared scale back to the Q-scale using the per-rho parameters:
    $$\text{pmin\_q}_k = \frac{q_{\text{org}} - \ell_k}{\sqrt{2\ell_k}} \cdot \sigma_{Q,k} + \mu_{Q,k}$$

    where $\sigma_{Q,k}$ and $\mu_{Q,k}$ are the per-rho Liu standard deviation and mean (note: $\sigma_{Q,k}^2 = \text{varQ}_k$ used in line 1538).

// Lines 1523-1546: pmin -> Q scale mapping
boost::math::chi_squared chi2_df(l_k);
double q_org = boost::math::quantile(
    boost::math::complement(chi2_df, pmin));
double varQ_k = liu_rho_vec[k].sigmaQ * liu_rho_vec[k].sigmaQ;
pmin_q(k) = (q_org - l_k) / std::sqrt(2.0 * l_k)
           * std::sqrt(varQ_k) + liu_rho_vec[k].muQ;
Important: R uses qchisq(1 - pmin, df = l) with a central chi-squared distribution (no noncentrality parameter), even when the Liu fit found $\delta > 0$. The noncentrality is only used in the forward direction (computing p-values). The inverse mapping deliberately uses the central quantile. This is visible in the R source code and faithfully replicated here (line 1529).

9. Step 7 — Integration (Adaptive Gauss-Kronrod)

7

Compute P(T_SKATO > observed) via numerical integration

The SKAT-O p-value is computed as:

$$p_{\text{SKAT-O}} = 1 - \int_0^{40} f(x)\, dx$$

where the integrand $f(x)$ combines the CDF of the null distribution (evaluated at the minimum-over-rho threshold) with the $\chi^2(1)$ density of the mixing variable.

9a. The Integrand Function

For each quadrature point $x$ (representing a realization of the $\chi^2(1)$ mixing variable):

$$f(x) = \underbrace{F_Q\!\left(\min_k \frac{\text{pmin\_q}_k - \tau_k \cdot x}{1 - \rho_k}\right)}_{\text{CDF of null Q distribution}} \;\times\; \underbrace{\phi_{\chi^2(1)}(x)}_{\text{mixing density}}$$

The steps inside the integrand (lines 1580–1635):

  1. Compute $\phi_{\chi^2(1)}(x)$ via boost::math::pdf(chi2_1, x)
  2. For each $\rho_k$, compute the adjusted threshold: $$\text{temp}_k = \frac{\text{pmin\_q}_k - \tau_k \cdot x}{1 - \rho_k}$$
  3. Find $\text{temp\_min} = \min_k \text{temp}_k$
  4. Early-out: if $\text{temp\_min} > \sum\lambda_{\text{shared}} \times 10^4$, return $\phi(x)$ (CDF is effectively 1)
  5. Standardize using the shared parameters:
    $$\text{min1\_st} = (\text{temp\_min} - \text{MuQ}) \cdot \text{sd1} + \text{MuQ}$$
    where $\text{sd1} = \sqrt{(\text{VarQ} - \text{VarRemain}) / \text{VarQ}}$ accounts for the cross-term variance $\text{W3.3.item}$
  6. Compute $P(Q > \text{min1\_st} \mid \lambda_{\text{shared}})$ via one Davies call with the shared eigenvalues
  7. Return $(1 - \text{tail\_prob}) \times \phi_{\chi^2(1)}(x)$
// Lines 1596-1600: min threshold across rhos
double temp_min = std::numeric_limits<double>::infinity();
for (int k = 0; k < n_rho; k++) {
    double val = (pmin_q(k) - tau(k) * x) / (1.0 - rho_capped(k));
    if (val < temp_min) temp_min = val;
}

// Lines 1611-1613: standardize
double min1_st = (temp_min - MuQ) * sd1 + MuQ;

// Lines 1618-1619: ONE Davies call with shared lambda
double tail_prob = davies_pvalue(min1_st, lambda_shared);
Efficiency: The integrand calls Davies with the shared eigenvalues (from $\mathbf{W}_{3.2}$), not the per-rho eigenvalues. This is the key computational optimization in the R SKAT package — the eigendecomposition is shared, and only the threshold changes with $x$ and $\rho$.

9c. Liu Fallback Integration Path

If any Davies call inside the integrand fails (lines 1620–1622 set davies_failed_in_integrand = true), the entire integration is redone with a Liu-based integrand (lines 1657–1717). The Liu fallback differs in two ways:

  1. No sd1 standardization: Uses $\text{temp\_min}$ directly instead of $\text{min1\_st}$ (line 1690)
  2. Central chi-squared CDF: Instead of Davies, uses
    $$\text{temp\_q} = \frac{\text{temp\_min} - \text{MuQ}}{\sqrt{\text{VarQ}}} \cdot \sqrt{2\,D_f} + D_f$$
    where $D_f = (\sum\lambda_{\text{shared}}^2)^2 / \sum\lambda_{\text{shared}}^4$ is the Pearson-type degrees of freedom (line 1662). Then: $\text{CDF} = P(\chi^2(D_f) \leq \text{temp\_q})$. 
// Lines 1660-1662: Pearson df for Liu fallback
double sum_lam2 = arma::sum(lambda_shared % lambda_shared);
double sum_lam4 = arma::sum(lambda_shared % lambda_shared
                           % lambda_shared % lambda_shared);
double Df_shared = sum_lam2 * sum_lam2 / sum_lam4;

10. Step 8 — Final P-Value with Safeguards

8

Multi-correction and bounds

After integration, the raw SKAT-O p-value undergoes several corrections (lines 1720–1763):

10a. Convert integral to p-value

$$p_{\text{SKAT-O}} = 1 - \int_0^{40} f(x)\, dx$$

10b. Bonferroni bound

Ensure $p_{\text{SKAT-O}} \leq p_{\min} \times n_\rho$ (line 1724–1727):

double bonf = pmin * (double)n_rho;
if (bonf < p_skato) p_skato = bonf;

10c. Multi correction

From SKAT_META_Optimal_Get_Pvalue (lines 1736–1746):

$$\text{multi} = \begin{cases} 2 & \text{if } n_\rho < 3 \\ 3 & \text{otherwise} \end{cases}$$ $$\text{pval1} = p_{\min} \times \text{multi}$$

If $p_{\text{SKAT-O}} \leq 0$ or any per-rho p-value is $\leq 0$, replace with $\text{pval1}$ (line 1744).

10d. Zero p-value rescue

If $p_{\text{SKAT-O}} = 0$, use the minimum of positive per-rho p-values (lines 1748–1759).

10e. Rank-1 Phi guard

Before entering the SKAT-O pipeline, if $m \leq 10$ and $\text{rank}(\Phi) \leq 1$, the algorithm forces pure SKAT ($\rho = 0$), skipping the integration entirely (lines 1878–1888). This matches R's guard: if (qr(Phi)$rank <= 1) r.corr = 0.

Small numerical differences in $\Phi$ (e.g., from SPA adjustment for binary traits) get amplified through the SKAT-O pipeline, leading to the ~5–8.5% relative discrepancy observed in validation. Understanding this chain explains why SKAT-O is inherently sensitive to tiny input perturbations.

Total amplification: End-to-end, a $5.6 \times 10^{-5}$ perturbation in $\Phi$ can produce a ~5–8.5% change in $p_{\text{SKAT-O}}$. This is intrinsic to the algorithm's design: the SKAT-O correction integrates over a steeply varying function near the tail boundary. The Liu moment-matching approximation (used in the qchisq inverse step) introduces the largest controllable error, but replacing it with exact Davies quantile inversion was found to be 13x slower for only 0.5% improvement (see CLAUDE.md validation notes).
